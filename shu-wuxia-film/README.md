# 世新大學新聞系的武功秘笈｜手繪線稿動畫短片

以程式碼繪製的手繪線稿風格動畫：紅底紙紋、白色線條「邊畫邊出現」、帶手繪抖動（line boil），夜景改為深藍底紅線並加上燈火光暈。每個場景都有一個會動的金庸武俠事件；世新新聞系系徽畫在片名卡、片尾，其他場景則常駐左上角。

## 製作流程（全部以程式產生）

1. **旁白**（`tts/make_vo.py`）：Kokoro-82M（ONNX，離線）男聲 `zm_yunyang`，語速 0.80；中文 G2P 採 misaki，另外手動校正多音字與武俠人名（木柵 mù zhà、降龍 xiáng lóng、重劍 zhòng jiàn、乾坤 qián kūn、為國為民 wèi）。每句生成後量測秒數（`tts/vo/manifest.json`），並檢查 NaN、削波與失真。
2. **時間軸**（`build_timeline.py`）：場景長度＝前導＋各句實測秒數＋句間停頓＋收尾。轉場期間不放旁白；畫面、字幕、音效、配樂都讀同一份時間軸。
3. **畫面**（`render/`）：SVG 向量線條。元件包括山、祥雲、溪流、海浪、松、竹、建築、山洞口、牌坊、城牆、印報機、人物骨架（含 IK）、龍、神鵰、白鶴、系徽、秘笈等，都可重複使用。線條以筆刷帶狀填色並逐步畫出，每 3 格重算一次手繪抖動。所有物件先填紙色再描邊、由遠而近繪製，所以前景一定遮住後景。每場都有視差鏡頭推移，另有雲、水、煙、落葉、行走等持續動態。Chromium 逐格渲染，每格等畫面完整繪製後才擷取，無損串流到 ffmpeg（`render/render.mjs`）。
4. **配樂**（`audio/music.py`、`audio/synth.py`）：原創武俠風，132 BPM，羽調五聲音階（收尾轉宮調）。古箏、琵琶輪指、笛子、二胡、弦樂、大鼓、堂鼓、鑼、鈸、木魚都以程式合成；情緒隨各場編配起伏，重擊點精準對齊畫面。
5. **音效**（`audio/sfx.py`）：劍光、刀劍撞擊、掌風、龍吟、碎石、浪濤、鵰鳴、翻頁、印報機等全部合成，觸發時間直接由場景程式匯出（`render/export_cues.mjs`）。
6. **混音**（`audio/mix.py`）：旁白出現時配樂自動壓低 14 dB、音效壓低 8 dB；整體正規化到 −15 LUFS，True-peak limiter 設在 −1.5 dBTP。
7. **字幕**（`subs/make_subs.mjs`、`finalize.py`）：產生雙語 SRT，並把字幕卡逐格合成進畫面（淡入淡出）。
8. **品管**（`qa/`）：自動逐格檢查空白、破圖黑洞、紙紋缺失、配色異常、突兀跳變與凍結格，另做旁白清晰度、響度與頻譜檢查，並抽幀人工複檢。

重建全部：`./make_all.sh`（需要 ffmpeg、Node 22＋Playwright/Chromium、`requirements.txt`，以及 Kokoro 模型：npm 套件 `kokoro-fp16-shards`、`kokoro-js` 的 voices；fp16 權重需先轉為 fp32，才能避免部分句子出現 NaN）。

## 注意

- **系徽**：採用世新新聞系官方 LOGO（系上臉書專頁公布的版本：地球、軌道環上的「SHU」、頭部圓點與繞過地球的毛筆身軀、「!」，以及「世新／新聞」題字）。以 `assets/logo/trace_logo.py` 把參考圖（`assets/logo/reference.png`）描成向量外框，產生 `render/lib/logo_data.js`，再由 `render/lib/props.js` 的 `emblem()` 以程式繪出：先描外框、再填白、題字逐字刷上。系徽出現在片名卡、片尾，以及每個敘事場景的左上角。
- **「乾淨版不上口白」**：已同時提供「無字幕、有旁白」與「無字幕、無旁白」兩種乾淨版，可依用途選擇。
- **字型**：中文用芫荽 Iansui（依教育部國字標準字體，例如「兼」上方為「丷」；原先的霞鶩文楷 TC 採傳承字形，會把「兼、為、真、這」等字寫成舊字形，因此更換），英文用 Cormorant Garamond（皆 SIL OFL，由 `assets/fetch_fonts.py` 下載），缺字備援為 Noto Sans/Serif CJK。Iansui 只有一種字重，粗體以同色細描邊模擬。
